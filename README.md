# CineVerse Travel Co. (Marvel Edition)

A cinematic travel app for exploring destinations across the Marvel Cinematic Universe.

## ✨ Features

- Browse destinations like Knowhere, Wakanda, and the Quantum Realm
- Dynamic routing for each location
- Modular "mini-apps" for each destination
- Styled with a Marvel-inspired dark theme
- Built with React + Vite
